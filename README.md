# DataRepo

**What was the problem you were solving in the projects for this course?
The primary problem in this course project was designing a system to efficiently manage and organize a collection of course data for a Computer Science program. This involved tasks such as storing course information, handling relationships like prerequisites, and providing functionalities to sort, search, and display the courses in alphanumeric order.

How did you approach the problem? Consider why data structures are important to understand.
My approach involved finding a suitable data structure, which I ended up choosing a Binary Search Tree (BST). The BST was chosen for its ability to maintain an ordered structure, allowing efficient insertion, retrieval, and sorting of course data. Understanding data structures was very important as the choice directly impacted the system's efficiency and functionality.

How did you overcome any roadblocks you encountered while going through the activities or project?
Several challenges arose, such as ensuring proper handling of edge cases (e.g., inserting courses with the same ID or handling an empty data set).

Breaking Down the Problem: Isolating the issue to a specific function or logic.
Incremental Testing: Testing smaller pieces of code to confirm they worked independently.

How has your work on this project expanded your approach to designing software and developing programs?
This project highlighted the importance of selecting appropriate data structures early in the design process and considering their pros & cons. Also, working with real-world data formats like CSV files was a very nice hands on learning approach. 

How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

Readable Code: Using clear naming conventions and comments to make the code self-explanatory.
Modular Design: Breaking the program into separate functions for insertion and data-loading
Adaptability: Designing the BST to handle dynamic data and adding functionalities like prerequisite management to make the system extensible for future requirements, as well as ensuring the CSV can be updated live and the code can adapt to that.
